# Morrow Polaris — cofre de demonstração

## Abrir

1. Inicie o Morrow Polaris.
2. Escolha **Abrir uma pasta** e selecione demo/vault/ neste repositório.
3. Abra a página favorita **Comece aqui — demonstração** na barra lateral.
4. Siga os percursos. As páginas, tabelas e assets já estão no cofre; o gerador não é necessário para abrir.

O script demo/.morrow-tools/build-demo.mjs recria o cofre com conteúdo determinístico quando executado da raiz do repositório: node demo/.morrow-tools/build-demo.mjs. A validação automatizada pode ser executada com npx vitest run --config demo/.morrow-tools/vitest.config.mts.

## Proveniência e privacidade

Todos os nomes, números, imagens, capas e símbolos são sintéticos. Os SVGs em demo/vault/attachments/ foram desenhados como formas geométricas locais para esta demonstração; não foram baixados de sites nem derivados de retratos, marcas ou vaults pessoais. Não há URLs de imagem, contas, dados bancários reais ou conexões externas. O link dentro da célula rica aponta para demo.invalid e serve somente como exemplo de texto vinculado.

Os arquivos demo/vault/.morrow/workspace.json e recent.json dão IDs estáveis às páginas e destacam a página inicial. Não copie este cofre sobre um vault pessoal.
