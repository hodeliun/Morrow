# Criar ou vincular relação inversa com prévia de dados

## Parent

https://github.com/hodeliun/Morrow/issues/25

## What to build

Sugerir campo inverso ao criar relation e permitir conectar duas relações existentes depois.

Itens de origem: 19.

## Acceptance criteria

- [ ] Após escolher destino, oferecer criar inversa, usar coluna existente compatível ou manter unidirecional.
- [ ] Colunas existentes com dados apresentam união de pares em prévia antes de aplicar; nenhum vínculo é apagado silenciosamente.
- [ ] Conflitos de cardinalidade, destino, auto-vínculo e inversa já ocupada bloqueiam antes de mutar.
- [ ] Editar qualquer lado mantém proprietário/inversa projetada existentes, sem duplicar pares; desfazer e desvincular preservam dados.
- [ ] Testes cobrem zero/um/múltiplos vínculos, self-relation válida, dados preexistentes e round trip/reabertura.
