# Paridade de configuração de formato para resultados de fórmula

## Parent

https://github.com/hodeliun/Morrow/issues/25

## What to build

Usar o mesmo editor de formato para tipos calculados e campos Formula com o mesmo tipo de resultado.

Itens de origem: 18.

## Acceptance criteria

- [ ] Formula → Number oferece a mesma precisão/localidade/apresentação de Number em modo calculado.
- [ ] Formatos suportados moeda/percentual/data/duração/escala reutilizam suas opções válidas e persistência.
- [ ] Trocar formato mantém expressão/bindings; não oferecer default ou edição manual como se alterassem resultado derivado.
- [ ] Resultado incompatível mostra diagnóstico sem coerção/perda; zero/null/false não são confundidos.
- [ ] Teste de sessão/reabertura e UI compara as duas rotas de autoria para resultados equivalentes.
