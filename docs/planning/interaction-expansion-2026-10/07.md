# Navegação de células com seleção e edição explícitas

## Parent

https://github.com/hodeliun/Morrow/issues/25

## What to build

Introduzir foco de grade previsível para clique, Tab, Enter, setas e editores especializados.

Itens de origem: 6.

## Acceptance criteria

- [ ] Clique seleciona célula; Enter/F2/duplo clique edita; Escape cancela rascunho.
- [ ] Tab/Shift+Tab navegam células visíveis sem focar expandir linha; Enter confirma e desce, Shift+Enter sobe.
- [ ] Texto multilinha usa Enter para nova linha e Ctrl+Enter para confirmar; dropdowns conservam suas setas.
- [ ] Grade usa roving focus e mantém expandir linha alcançável por atalho/menu; fronteiras não criam linha implicitamente.
- [ ] UI cobre scroll/congelamento/colunas ocultas e revalidação de foco após filtro/sort.
