# Issue tracker

The active tracker is the public fork's GitHub Issues:
https://github.com/hodeliun/Morrow/issues. GitHub is authoritative for issue
status, assignment, labels, and blocking relationships. `docs/issues.json` is a
read-only snapshot of the public issues at the time of the Polaris migration.

Issue #1 records the migration and blocks the five correction issues #2–#6.
Do not edit or renumber those issues as part of unrelated work. Create future
issues in this fork and record their public URLs here or in the snapshot; never
carry private tracker IDs into this repository. `docs/tickets/` contains
historical implementation notes and is not a competing active tracker. Verify
acceptance evidence before closing an issue.
