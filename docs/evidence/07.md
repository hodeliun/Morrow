# Ticket 07 — Named controls and calculated document results

Implementation evidence for ticket 07, completed locally on 2026-10-26. Review evidence is recorded separately.

## Delivered

- Added page-scoped named controls for text, number, slider, select, checkbox, date, and single or multiple relation values. The editor's `/` menu inserts controls and calculated results; controls can be configured, renamed, and deleted inline. Reset remains available through the command seam.
- Persisted current/default control values in `morrowControls` frontmatter. Formula result and linked-view blocks round-trip through Markdown markers while retaining readable fallback text.
- Added stable ID bindings from formulas and view filters to controls and results. Renames preserve bindings, deleted references show diagnostics, duplicate names and cross-scope collisions are marked ambiguous, and reference selectors distinguish duplicate names by ID suffix.
- Added typed formula result display with currency, number, percent, and progress formatting, validation, cycle/depth errors, and save/cancel handling. Evaluation only reads workspace state.
- Linked database views share the source rows and keep independent filter settings. Page duplication and block paste remap identities for copied controls/results and internal references; references outside the copied content remain external.
- Added schema version 8 migration defaults, strict control metadata checks, relation target/row validation, and read-only UI guards. Relation selectors hide trashed tables, and saved references to unavailable tables or rows show localized diagnostics.
