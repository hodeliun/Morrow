# Ticket 01 — Base isolada e CI

Data: 2026-10-26

## Alterações

- Identidade de produto definida como `Morrow Polaris`, com `appId` `io.github.hodeliun.morrowpolaris` e nome de pacote `morrow-polaris`.
- O perfil instalado usa `%APPDATA%/Morrow Polaris` no Windows (ou `appData/Morrow Polaris` nos demais sistemas), com dados de sessão Chromium em `Session`. O override `MORROW_USER_DATA` continua disponível para desenvolvimento e testes.
- A criação do primeiro vault usa `Documents/Morrow Polaris` e incrementa o nome se necessário; não seleciona o diretório padrão `Documents/Morrow` do Morrow original.
- Atualizações remotas e instalação de releases foram removidas desta edição privada. A tela informa que não há consulta de rede. O helper puro de comparação de versões foi mantido.
- CI de push/PR executa `npm ci` e `npm run check` em Linux e Windows. O workflow herdado que anexava artefatos a releases foi removido; a configuração de `electron-builder` não aponta para publicação.
- A licença Apache-2.0 e a atribuição upstream foram preservadas.

## Verificações

Ambiente local: Node `v24.15.0`, npm `11.12.1`.

- `npm ci`: concluído; 726 pacotes instalados e 727 auditados.
- `npm run check`: concluído. Typecheck e lint passaram; 17 arquivos de teste passaram com 181 testes; o comando também concluiu os builds de renderer, Electron e MCP.
- `git diff --check`: passou.
- Metadados de `package.json` e `package-lock.json`: nomes sincronizados; `appId` Polaris; sem configuração de publicação.

## Limitações e baseline

- O npm reportou 5 vulnerabilidades nas dependências resolvidas (1 moderada e 4 altas). Nenhuma atualização de dependências foi feita neste ticket.
- A aplicação não foi aberta nem instalada. O isolamento de perfil foi verificado no código/configuração; a abertura lado a lado não foi exercitada.
- Nenhuma release foi publicada. A consulta/instalação de atualizações permanece desativada nesta edição privada; um canal autenticado ou público deverá ser projetado antes de oferecer atualizações.
- A CI foi configurada localmente para Linux e Windows; não foi iniciada uma nova execução remota após estas alterações.
