# Ticket 06 — Bases de dados vinculadas e visualizações

## Entrega

- Adicionadas visualizações vinculadas que reutilizam as linhas da base de origem e mantêm configurações independentes por bloco, com IDs próprios para blocos e visualizações duplicados.
- As visualizações vinculadas oferecem filtros, ordenação, agrupamento, resumos, formatação condicional, layout de galeria e calendário; referências de origem são exibidas separadamente das abas da base.
- Exclusões e alterações de esquema verificam vínculos ativos e dependências de fórmulas. Referências indisponíveis existentes podem ser preservadas em edições comuns, mas referências inválidas novas, ciclos e retargeting são rejeitados.
- A configuração sobrevive à serialização em Markdown com marcador oculto e fallback legível. Rótulos novos foram traduzidos para inglês, português e espanhol.

## Evidências

- Testes de banco, comandos e Markdown cobrem vínculos, persistência, filtros, agrupamentos, fórmulas, referências quebradas e exclusão de páginas: 58 testes focados passaram.
- `npm run check`: sucesso — typecheck, ESLint, 253 testes em 29 arquivos e builds do renderer, Electron e MCP.
- O build do renderer emitiu um aviso de chunk: `DatabaseView.tsx` é importado de forma dinâmica e estática, então não será separado em outro chunk. O build terminou com sucesso.
- Nenhum vault pessoal foi usado nem a interface foi aberta; a validação visual fica para o principal.

## Limites

- A visualização compartilha os dados da base de origem; filtros e configurações afetam apenas a visualização vinculada.
- A validação de interface permanece pendente no principal, que executará o Electron conforme as instruções do ticket.
